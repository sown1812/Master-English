## LO TRINH HOC TIENG ANH GAMIFIED

1. Tong quan: 3 quest theo muc tieu
   - Quest IELTS (Academic): Band 4.0 -> 9.0, Writing/Speaking formal, cho sinh vien/du hoc.
   - Quest TOEIC (Business): 300 -> 990, Email/Meeting/Chuyen nganh, cho nguoi di lam.
   - Quest Communication (Life): Giao tiep hang ngay, speaking/listening thuc te, cho du lich/sinh song.
   - Moi quest chia theo 6 cap CEFR: A1 -> A2 -> B1 -> B2 -> C1 -> C2.

2. Co che gamification chinh
   - XP & Level: 50-100 XP/bai, 500 XP/unit, 2000 XP/level CEFR; bonus perfect +25% XP.
   - Streak: +5% XP/ngay lien tuc (toi da +50%); freeze card, recovery bang gems.
   - Achievements/Badges: Vocabulary 100/500/1000, Quest Master, Listening Pro, Speaking Champion, etc.
   - Leaderboard: Global (week/month/all-time), Friends, Guild; thuong XP + badge.
   - Currency: Coins free (hint/power-up), Gems premium (freeze, booster, avatar).

### 2.3 Achievements & Badges System
- Learning Achievements:
  - "First Steps": Hoan thanh bai hoc dau tien
  - "Vocabulary Novice": Hoc 100 tu
  - "Vocabulary Expert": Hoc 500 tu
  - "Vocabulary Master": Hoc 1000 tu
  - "Grammar Foundation": Hoan thanh tat ca grammar A1-A2
  - "Grammar Guru": Hoan thanh tat ca grammar quests
  - "Listening Pro": 100 bai listening hoan thanh
  - "Speaking Champion": 100 bai speaking practice
  - "Writing Wizard": 50 bai writing hoan thanh
- Quest Achievements:
  - "Quest Starter": Hoan thanh Unit dau tien
  - "Quest Warrior": Hoan thanh 10 Units
  - "Quest Master": Hoan thanh 1 lo trinh hoan chinh
  - "Multi-Quest Hero": Hoc 2+ lo trinh dong thoi
  - "Career Expert": Hoan thanh 1 specialization module
- Social Achievements:
  - "Team Player": Tham gia Guild
  - "Guild Leader": Tao Guild va co 10+ members
  - "Helpful Mentor": Giup do 10 nguoi hoc khac
  - "Social Butterfly": Ket ban voi 20 nguoi
- Challenge Achievements:
  - "Perfect Week": 7 ngay lien tiep diem toi da
  - "Speed Runner": Hoan thanh 10 bai trong 1 ngay
  - "Night Owl": Hoc sau 10pm
  - "Early Bird": Hoc truoc 7am

3. Quest IELTS (rut gon)
   - A1-A2 Foundation: Personal info, family, routines, hobby; boss: Speaking Part 1 sim.
   - B1-B2 Intermediate: Writing Task 1 (charts/process), Task 2 (opinion/discussion), Listening full tests.
   - C1-C2 Advanced: Complex writing, paraphrase, idioms, Speaking Part 2-3 mastery; final boss: Full test mock.

4. Quest TOEIC (rut gon)
   - A1-A2: Office life, requests, email basics; boss: Part 1 photos.
   - B1-B2: Meetings, presentations, negotiation; boss: Part 3 conv + Part 7 passages.
   - C1-C2: Exec communication + nghe Part 1-4 full; career modules (Finance/IT/Healthcare/Hospitality) voi boss case study.

5. Quest Communication (rut gon)
   - A1-A2: Survival topics (introduce, buy food, ask directions).
   - B1-B2: Travel, social small talk, job interview basics, culture tips.
   - C1-C2: Debate, story-telling, humor/idioms; boss: roleplay da chu de.

6. Chuan hoa do kho CEFR
   - Mapping XP/level: A1 (1-10), A2 (11-20), B1 (21-30), B2 (31-40), C1 (41-50), C2 (51-60).
   - Moi unit co grammar + vocab + skill (L/S/R/W) voi muc tieu CEFR ro rang.

7. Cau truc bai hoc chuan
   - Warm-up (2-3 phut), Vocab set (20-40 tu, flashcard + audio), Grammar micro lesson, Practice (MCQ/fill/matching), Speaking/Listening mini, Boss/Quiz cuoi bai.
   - Module boss: mock test ngan (IELTS/TOEIC/roleplay) + feedback tu dong.

8. Tinh nang doc dao can co
   - AI Speaking Partner: feedback stress/intonation; offline cache mau audio de luyen.
   - Career modules: bai chu de nghe nghiep (finance/IT/healthcare/hospitality).
   - Daily/weekly quest: 3 nhiem vu nho, boss tuan la mock test 15 phut.
   - Offline mode: cache lesson + audio; queue progress -> sync khi online.

9. He thong theo doi tien do
   - Dashboard CEFR + % unit/lesson da hoan thanh + streak + XP/week.
   - Report theo quest (IELTS/TOEIC/Comm) va theo ky nang (L/S/R/W).
   - Mini-test dinh ky: cuoi unit, cuoi level (CEFR checkpoint) de de-xuat lo trinh tiep.

10. Monetization (goi y)
    - Freemium: khoa 30% bai nang cao, gioi han booster/freeze.
    - Premium: mo khoa toan bo quest + AI Speaking Partner nang cao + career modules + streak protection.
    - IAP: gems goi nho, avatar/skin, booster XP.

## 💾 Database Schema Đơn Giản

### WordEntity
```kotlin
@Entity(tableName = "words")
data class WordEntity(
    @PrimaryKey val id: Int,
    val word: String,              // "hello"
    val translation: String,       // "xin chào"
    val pronunciation: String,     // "həˈloʊ"
    val partOfSpeech: String,      // "noun", "verb", etc.
    val exampleSentence: String,   // "Hello, how are you?"
    val lessonId: Int              // Thuộc lesson nào
)
```

### LessonEntity
```kotlin
@Entity(tableName = "lessons")
data class LessonEntity(
    @PrimaryKey val id: Int,
    val title: String,             // "Greetings"
    val description: String,       // "Learn basic greetings"
    val order: Int,                // Thứ tự lesson
    val totalWords: Int,           // Số từ trong lesson
    val isUnlocked: Boolean        // Đã mở khóa chưa
)
```

### UserProgressEntity
```kotlin
@Entity(tableName = "user_progress")
data class UserProgressEntity(
    @PrimaryKey val id: Int = 1,   // Chỉ có 1 user (local)
    val currentLevel: Int,          // Level hiện tại
    val totalXP: Int,               // Tổng XP
    val wordsLearned: Int,          // Số từ đã học
    val lessonsCompleted: Int,      // Số bài đã hoàn thành
    val lastStudyDate: Long         // Timestamp
)
```
